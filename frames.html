Frame fixture

A test page for Willow's cloud browser. It holds three frames from other sites. Each one tries to open an example.com address that carries a made-up Google Form submit address (https://docs.google.com/forms/d/e/willow-probe-fixture/formResponse). The browser's safety gate must refuse all three loads, and this page must stay where it is.

Nothing here is real: the form id names no form, and no address on this page goes to Google. If a gate failed, the frame would show example.com's sample page. Add ?frame=at-once, ?frame=moves-itself or ?frame=re-pointed to show one frame alone.

2. A frame that moves itself

Its own page is the one-line document below, served back by httpbin.org's base64 echo (a public HTTP test service), so the frame is on another site. Half a second after it loads, it sends itself to its address.

<!doctype html><meta charset="utf-8"><title>Frame 2</title><p>This frame moves itself half a second after it loads.</p><script>addEventListener("load", function () { setTimeout(function () { location.href = "https://example.com/?frame=moves-itself&next=https%3A%2F%2Fdocs.google.com%2Fforms%2Fd%2Fe%2Fwillow-probe-fixture%2FformResponse"; }, 500); });</script>

3. A frame this page re-points

It first loads example.com's sample page; half a second after that, this page points it at its address.
